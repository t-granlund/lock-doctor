03 · The anchor, named

Why today’s site holds you still

“Hostinger Horizons” isn’t just a platform label — it’s the dependency. The site is a generated app with no source you own, no git history, and edits that must pass through the vendor’s tool. Whoever manages it today, the shop can’t fix, move, or grow it alone.

Today’s dependencies

The builder account · the generated code nobody can read · per-edit costs or wait times · hosting locked to the platform · no tests, no backups story, no way to leave without starting over.

Tomorrow’s ownership

Static files you own (Apache-2.0) · source in your own git mirror · any host, or none · the agent maintains it in plain language · leaving costs nothing because everything is already yours.

Security & privacy

Local-first files · customer PII stays out of prompts by default · nothing consequential runs without a human yes · API keys live in your config, never in a prompt. The harness makes care easy to do and hard to skip.

Marketing & reporting

Listing consistency audits (Google, Bing, Yelp, Facebook) · review follow-through with the send button yours · the Friday one-pager: jobs, revenue by service, reviews, no-shows, low stock.

Analytics, owned

Privacy-friendly, self-owned analytics — or keep what you love. No third-party pile of your customers, no tracking you didn’t choose, numbers that land on one page instead of five logins.
